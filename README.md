# VoGU Study

Учебный репозиторий по дисциплинам ВоГУ.

## Структура

- `Информатика и основы программирования/` — лабораторные отчёты и исходники C++.
- `Высшая математика/` — материалы по вышмату.
- `Основы права и противодействие коррупции и экстремизму/` — семинары и материалы по дисциплине.
- `00_Входящие/` — временное место для новых файлов до сортировки.
- `99_Шаблоны/` — правила оформления и шаблоны.

## Информатика и основы программирования

Текущий вариант лабораторных работ: **№8**.

Готовые и перепроверенные лабораторные работы: **№1–5**.

Основное оформление отчётов: Times New Roman, 14 pt для основного текста, межстрочный интервал 1,5; абзацный отступ 1,25 см; поля: слева 3 см, справа 1,5 см, сверху и снизу 2 см. Листинги программ и крупные таблицы сделаны компактнее для читаемости и сохранения верстки.
