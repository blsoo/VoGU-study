# Компьютерная графика

Лабораторные работы выполнены по выданным методическим материалам.

- `ЛР1_Inkscape` — векторная графика: задания 1–4, контрольное задание Tux, исходники SVG, PNG-превью и отчет DOCX.
- `ЛР2_GIMP` — растровая графика: задания 1–4, контрольное задание варианта №8, исходные изображения, результаты и отчет DOCX.

Отчеты оформлены шрифтом Times New Roman 14 pt, межстрочным интервалом 1,5, абзацным отступом 1,25 см и полями 3 / 1,5 / 2 / 2 см. Титульная часть построена по выданному шаблону. Поля ФИО и группы оставлены для заполнения, так как этих данных в предоставленных материалах нет.
