# Компьютерная графика

Повторно проверенный комплект лабораторных работ по методическим материалам ВоГУ.

## Структура

- `ЛР1_Inkscape/` — лабораторная работа №1: векторная графика, Inkscape.
  - `Исходники/` — редактируемые SVG-проекты заданий 1–4 и контрольного задания.
  - `Результаты/` — PNG-превью выполненных заданий.
  - `Отчет/` — итоговый отчет DOCX и текстовая версия.
- `ЛР2_GIMP/` — лабораторная работа №2: растровая графика, Gimp.
  - `Исходные_файлы/` — материалы из выданного архива.
  - `Результаты/` — изображения по заданиям 1–4 и контрольному заданию.
  - `Отчет/` — итоговый отчет DOCX и текстовая версия.
- `FINAL_AUDIT.md` — результаты повторной проверки.

## Оформление отчетов

Итоговые DOCX приведены к формату A4: поля 3 / 1,5 / 2 / 2 см, основной текст Times New Roman 14 pt, межстрочный интервал 1,5, абзацный отступ 1,25 см. Титульная часть перестроена по выданному шаблону. Неизвестные данные студента (ФИО, группа, регистрационный номер по журналу) намеренно оставлены пустыми для заполнения.

## Важное техническое замечание по ЛР2

В рабочем окружении отсутствует исполняемый Gimp. Поэтому растровые результаты ЛР2 подготовлены по параметрам и последовательности из методических указаний, но нативные `.xcf`-проекты не создавались. В комплекте присутствуют исходные изображения, готовые растровые результаты и отчет; выдавать их за XCF-файлы не следует.
