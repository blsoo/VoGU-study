# Готово к сдаче

Эта ветка зафиксирована как финальная версия лабораторных по компьютерной графике после повторной проверки.

## Что лежит в Git

- ЛР1 Inkscape: исходники SVG, текст отчета, README.
- ЛР2 Gimp: текст отчета, README.
- общий FINAL_AUDIT.md с перечнем исправлений и повторной проверки.

## Как скачать с GitHub

Открой ветку `computer-graphics-final`, нажми **Code → Download ZIP**.

Прямая ссылка на ветку:
https://github.com/blsoo/VoGU-study/tree/computer-graphics-final/Компьютерная%20графика

## По готовым DOCX

Финальные DOCX и локальный полный ZIP были сформированы в рабочем окружении ChatGPT. Текущий GitHub-коннектор умеет записывать текстовые файлы и git-объекты, но не принимать локальные бинарные DOCX/ZIP напрямую, поэтому они не подменены фиктивными файлами в репозитории.
