# ЛР1 — Inkscape

Лабораторная работа №1 «Векторная графика. Работа в редакторе векторной графики Inkscape».

- `Исходники/Задание_1.svg` — полный набор упражнений задания 1.
- `Исходники/Задание_2.svg` — скрепка 256×256 px с сеткой 10 px.
- `Исходники/Задание_3.svg` — бильярдный шар №7.
- `Исходники/Задание_4.svg` — упражнения с текстом, включая глифы.
- `Исходники/Контрольное_задание_Tux.svg` — контрольное задание.
- `Отчет/Отчет_ЛР1_Компьютерная_графика.docx` — итоговый отчет A4 после повторной проверки.

Перед сдачей заполнить ФИО, группу и регистрационный номер на титульном листе и при необходимости переименовать проекты по схеме из методички: `Фамилия - Задание N`.
