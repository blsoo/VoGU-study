# ЛР2 — Gimp

Лабораторная работа №2 «Растровая графика. Работа в редакторе растровой графики Gimp».

В `Результаты/` после повторной проверки находятся отдельные результаты для изменения холста/изображения, рисования и заливки, клонирования одуванчика, удаления фонаря, гистограмм и цветокоррекции, фотоколлажа «Волшебная ночь», рекламного постера и контрольного задания варианта №8 «Ветеринарная клиника „Пушок“».

`Отчет/Отчет_ЛР2_Компьютерная_графика.docx` — итоговый отчет A4 после повторной постраничной проверки.

В текущем окружении Gimp не установлен, поэтому нативные XCF-файлы отсутствуют. Перед сдачей заполнить ФИО, группу и регистрационный номер на титульном листе.
